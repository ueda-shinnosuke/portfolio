# My portfolio（コーディング用スターター）

現在のデザインの良さを残しながら、レスポンシブ対応・作品絞り込み・スマホナビゲーションを加えたHTML/CSS/JavaScriptです。

## フォルダ構成

- `index.html`
- `css/style.css`
- `js/script.js`
- `img/`（画像を入れる場所）

## 最初にすること

`img/` フォルダに、現在使っている画像を次のファイル名で入れてください。

- `cloud1.png`（ファーストビューの雲）
- `work-aquarium.jpg`（水族館サイト）
- `work-medical.jpg`（医療系LP）
- `work-fireworks.jpg`（花火大会ポスター）
- `work-chocolate.jpg`（チョコフェスポスター）
- `video-01.jpg`（動画01のサムネイル）
- `video-02.jpg`（動画02のサムネイル）
- `video-03.jpg`（動画03のサムネイル）

既存の画像ファイル名を変えたくない場合は、`index.html` の該当する `src="img/..."` を実際のファイル名に変更してください。

## 注意

- 学校名・氏名・作品名・説明文は、公開前に正確な内容へ確認してください。
- 作品カードのリンクは仮で `#contact` にしています。作品詳細ページがある場合は、リンク先をそのURLに差し替えてください。
- お問い合わせ欄には、公開してよい連絡先を追加してください。
- 画像ファイルそのものはこのZIPには含めていません。
